# مِداد التعليمية

نسخة فعلية قابلة للتشغيل، وليست صفحة وهمية فقط.

## ما الموجود؟
- موقع عربي RTL متجاوب.
- تسجيل دخول حقيقي للطالب والأدمن.
- لوحة أدمن حقيقية لإضافة وتعديل وحذف المحتوى.
- إدارة الصفوف والمواد والملخصات والاختبارات.
- مساعد ذكاء اصطناعي للطلاب من خلال OpenAI API.
- قاعدة بيانات SQLite محلية.
- لا توجد مشاهدات أو أرقام وهمية في النسخة.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. ضع بيانات الأدمن ومفتاح OpenAI في `.env`.
4. شغّل:
   npm install
   npm start
5. افتح:
   http://localhost:3000

## ملاحظة أمنية
لا ترفع ملف `.env` إلى GitHub ولا تشاركه. غيّر كلمة مرور الأدمن قبل النشر العام إذا لزم.

## المساعد الذكي
المفتاح يبقى في الخادم ولا يظهر في المتصفح. إذا لم تضع OPENAI_API_KEY سيظهر المساعد للمستخدم مع رسالة أن خدمة الذكاء الاصطناعي غير مفعلة.
